# Reclaimed

Six bosses, reclaimed as playable survivors, following the way Seekers of the Storm made the False Son
playable: the boss you fight is untouched, and the survivor is unlocked by "purifying" that boss —
defeating it under a thematic condition.

| Survivor | Reclaimed from | Requires |
|---|---|---|
| Mithrix, King of Nothing | Commencement | base game |
| Voidling, Diviner of the Deep | The Planetarium | Survivors of the Void |
| Echo of Providence | Providence's echo | DLC4 |
| Anima Harvester | Soulbound Threshold | DLC4 |
| Solus Wing | Solutional Haunt | Alloyed Collective |
| Solus Heart | Alloyed Collective finale | Alloyed Collective |

**Status: early development (0.1.0).** The shared framework is in place; survivor kits are still being built.

## Install
Use r2modman or the Thunderstore Mod Manager. Dependencies are installed automatically.

Every balance number is in the BepInEx config (`com.reclaimed.*.cfg`) and in Risk of Options when installed.

## Multiplayer
Every player needs the mod. Unlocks are checked on the host and granted to each qualifying player.
